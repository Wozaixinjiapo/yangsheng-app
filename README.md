# 养生研习社 V2

手机端健康学习网页。包含24节基础课程、每日推荐、课后测验、AI咨询提问复制、通用7天生活方式模板、运动示例和本机健康记录。

## 部署
将 `index.html`、`manifest.webmanifest`、`README.md` 放到 GitHub 仓库根目录，Settings → Pages → Deploy from a branch → main / (root)。

## 重要说明
本应用不是医疗器械，不进行自动诊断或开具处方。AI咨询功能通过复制提问并打开 ChatGPT 使用，并未接入独立 AI API。课程目前为通用基础内容，尚未逐页接入用户上传的中医讲义。健康记录保存在当前浏览器 localStorage，请勿在共享设备存储敏感信息。
