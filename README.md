# 养生研习社 V3 · 个人进阶研修版

## H01 高血压专题

12个单元，采用理论与案例交替模式；6节理论与6节案例。内容包括血压机制、中医经典辨读、药理与中药安全、DASH营养、运动、证据评价及综合考核。

## 使用

将 `index.html` 和 `manifest.webmanifest` 上传到 GitHub 仓库根目录，GitHub Pages 使用 `main` 分支的 `/ (root)` 发布。建议在手机浏览器打开并添加到主屏幕。

## 隐私与安全

- 学习笔记和进度仅存于浏览器 localStorage；请定期导出 JSON 备份。
- 咨询功能只复制问题到 ChatGPT，未内置AI服务。
- 本课程为研修框架及扩展讲义试行版，不是诊疗指南全文，不提供诊断或处方。
- 古籍出处为用户已上传材料的检索线索，尚未完成逐页校勘；不要将讲师观点当作经典原文或临床试验证据。
